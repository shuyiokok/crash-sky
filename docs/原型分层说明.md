# Crash 局后弹窗 · 原型分层说明

## 如何运行

```bash
cd C:\Users\songting\lite-crash
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 http://127.0.0.1:5173 ）。

## 图层结构（与 Figma/墨刀清单一致）

| 图层名 | 代码位置 | 职责 |
|--------|----------|------|
| **Mask** | `src/prototype/layers/Mask.tsx` | 半透明黑遮罩 + 主体 `#0E1218` |
| **Top** | `src/prototype/layers/TopBar.tsx` | 单行历史（打开后每局最终倍率，左旧右新，超宽丢最左）、关闭 |
| **Chart** | `ChartMain` + `ChartCanvas` + `PlayersAside` | 曲线画布；右侧参与人（人数/资金/机器人结算） |
| **Bottom** | `src/prototype/layers/BottomCtrl.tsx` | 自动撤退 5.1X、下注 10000 / MAX / 下注 |
| **SettingTip** | `src/prototype/layers/SettingTip.tsx` | 「今日不再自动弹出」→ localStorage |

组装入口：`src/prototype/CrashPopup.tsx`  
样式：`src/prototype/crash-prototype.css`  
固定文案：`src/prototype/prototypeData.ts`

## 交互对照

1. **关闭** → 回到麻将主界面  
2. **今日不再自动弹出** → `localStorage` 按日期记住  
3. **自动撤退** → 勾选后飞行中达目标倍率自动兑现  
4. **MAX** → 金额填满当前免费筹码  
5. **下注** → 扣减筹码，本局生效  
6. **历史** → 展开/收起倍率标签  
7. **公式坠毁** → 起飞时按 `C=max(1,floor((1-h)/(1-X)))` 抽点，达点爆炸后进入下一局
